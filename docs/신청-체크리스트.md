## 승인 전에도 지금 할 수 있는 것

**채널 분석은 쿼터 상향을 기다릴 필요가 없다.** `search`(100 units) 대신 업로드
재생목록(3 units)을 타므로, 기본 10,000 으로 **채널 3,300개**를 돌릴 수 있다.

```
npm run yt:channel -- @핸들     # 채널 최근 50편 · 3 units
npm run yt:comments -- --max 50 # 댓글 · 영상당 1 unit
```

상향이 필요한 건 **검색(`yt:search`)뿐이다.** 페이지당 100 units 라 기본 한도로는
하루 99페이지가 끝이다.
