과제 — 관광 공공데이터로 인구감소지역에 사람이 가게 만든다. 광고가 아니라 크리에이터를 움직인다. 영상 한 편이 지자체 홍보물 백 개보다 멀리 간다.

대표 문장 — 여기서 찍으면 잘 된다(X) → 이 소재가 반응이 좋고, 여기서도 찍을 수 있다(O)

풀려는 문제

크리에이터는 잘 된 영상을 보고 따라 찍는다. 그래서 이미 찍힌 곳만 계속 찍힌다. 안 알려진 곳은 참고할 영상이 없어서 구조적으로 후보에서 빠진다.

  • 지자체는 장소를 홍보하지만, 크리에이터가 묻는 건 “이게 먹히는 소재인가”다
  • 관광 공공데이터 6.4만 곳은 소재로 검색할 수 없다 — 분류는 있어도 성과가 없다
  • “아무도 안 갔다”는 기회가 아니라 잘 될 증거가 없다는 신호로 읽힌다

해결 방법

장소가 아니라 소재(subject)를 성과의 단위로 삼는다. 유튜브에서 소재별 성과를 재고, 공공데이터에서 같은 소재를 찍을 수 있는 곳을 전부 펼친다.

  • 성과 = 조회수 ÷ 구독자(vsr) — 채널 크기를 지워야 작은 채널의 대박이 보인다
  • 소재 점수 × 희소성 가중치 1/log(1+영상수) = 숨 스코어
  • 화면은 “오일장 3.2× (정선·화개장터 기준)” 처럼 출처를 밝힌 소재 성적만 말한다

독자 발견 — 폐교는 TourAPI 에 아예 없어서 우리가 직접 승격시킨 소재다(334곳·감소지역 194). 그리고 구독자가 커져도 성과가 안 죽는 유일한 소재다(1만~10만 2.59 / 10만~100만 2.41). 나머지는 전부 1만 구독을 넘기면 급락한다. 좌표가 없어 지도에 못 찍던 것을 같은 읍면 TourAPI 좌표 평균으로 채웠다.

설명 원칙 — 심사·시연에서 이 순서로 말한다

  • ① 재료가 아니라 질문부터. “관광데이터를 썼다”가 아니라 “크리에이터가 다음 촬영지를 어떻게 정하는가”에서 시작한다
  • ② 가정을 잰 것을 보여준다. 서비스가 서 있는 두 가정을 직접 검정했고, 하나는 기각됐다. 기각된 쪽을 숨기지 않는 것이 이 발표의 신뢰다
  • ③ 아는 곳으로 증명한다. 정선 5일장은 추천 대상이 아니라 증거다 — 정선이 맞아야 곡성을 믿는다. 단 같은 목록에 섞지 않는다
  • ④ 못 재는 것은 그리지 않는다. 기관 화면(/admin)에서 방문자수·체류일 같은 KPI 를 뺐다. 담당자는 그 숫자로 예산을 짠다
  • ⑤ 빈 자리를 문장으로 채우지 않는다. 재료 없는 칸은 안 그린다. 형용사 대신 숫자, 배수는 3.2×, 예상치는 반드시 범위로
  • ⑥ 순위를 지어내지 않는다. 그럴듯하게 만들려고 만든 임계값·계수는 점수를 지어내는 것과 같다. 차이는 순위가 아니라 카드 내용으로 낸다
같이 일할 때 지켜야 하는 것 — 아래 넷은 “단순화하면 편해 보이지만 서비스 목적이 깨지는” 것들이다. 전체 목록과 이유는 CLAUDE.md 「절대 하면 안 되는 것」에 있다. ① 한국어·영어 점수판을 합치지 않는다(재래시장: 영어권 4.1배 / 한국어권 0.6배) · ② 배수를 그릴 자격은 score.ts canShowMultiplier 한 곳에서만 판정한다(신뢰구간 4배 안·하한 20편) · ③ 희소성 가중치를 빼지 않는다(빼면 서울·부산만 남아 주제와 정반대가 된다) · ④ 화면에서 YouTube API 를 직접 부르지 않는다(쿼터가 마르면 시연이 멈춘다).
현재 단계 — 수집·점수·실데이터 연결까지 완료. 남은 것은 소개글 확보(6%→30%), LLM 전량 태깅(지원금 이후), 크리에이터 사용자 테스트(0건). 운영 URL gwanjetap.netlify.app · 데이터는 로컬 SQLite 로 재생성한다(data/*.db 는 커밋하지 않는다).
